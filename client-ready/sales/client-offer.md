## What you receive

1. **Codebase inventory.** Languages, important directories, entry points, package manifests, lockfiles, scripts, and configuration files, with file and line references where available.
2. **Architecture and dependency map.** A diagram and plain-language description of the major components and their relationships. Inferred relationships are labeled; unresolved questions remain visible.
3. **Setup and handover notes.** Documented prerequisites, configuration variable names, setup commands found in the repository, and gaps a new maintainer should resolve. The report receives a manual review and redaction of sensitive values before delivery; paths and metadata are part of that check.
4. **Test and CI observations.** What test scripts and workflow definitions exist, what they appear to cover, and what cannot be established from a read-only review.
5. **Maintenance priorities.** Up to ten actionable items ranked by impact and effort, each supported by a repository reference, a stated uncertainty, or both.
6. **One 30-minute walkthrough** and **one consolidated revision** to correct errors or clarify findings within the agreed scope.

Delivery is a Markdown report with a diagram and an HTML copy when available. It identifies the reviewed commit so the evidence can be checked later. This is a documentation and handover service; it does not certify security, compliance, production readiness, or correctness. A static observation is never presented as proof that an application or test passes.

## Access and confidentiality

The client confirms it owns the repository or has permission to authorize this review. Access should be a time-limited, read-only repository invitation or a source archive for the agreed commit. Do not send production credentials, customer records, private keys, or secret values. Repository access and report contents stay private unless the client explicitly authorizes publication.

The proposal identifies any approved subcontractor before that person receives private source code or a private report. Independent quality review starts with a public sample wherever practical; private client material is shared only after the client agrees to the named reviewer and access scope. No private repository content is uploaded to third-party AI or analysis services without the client's specific consent. Access is revoked at completion; temporary working copies are deleted within the retention period agreed below.
